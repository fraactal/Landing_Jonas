Política de privacidad

Última actualización: 2 de octubre de 2026

Esta Política de privacidad explica cómo jonathanvaldes.com trata información relacionada con las personas que visitan el sitio, envían una consulta, usan WhatsApp o agendan una conversación.

1. Identidad

Este sitio corresponde a Jonathan Valdés y se publica bajo el dominio jonathanvaldes.com.

2. Datos que podemos tratar

Cuando una persona usa el formulario o la agenda, puede entregar voluntariamente datos como nombre, empresa, email, teléfono opcional, tipo de necesidad, mensaje, fecha y hora solicitada para una reunión y datos necesarios para coordinar un diagnóstico tecnológico.

Como parte del funcionamiento técnico normal, proveedores de hosting, CDN o infraestructura pueden tratar registros técnicos como dirección IP, fecha y hora de acceso, página solicitada, navegador, sistema operativo o eventos técnicos similares.

No usamos deliberadamente cookies comerciales, perfiles publicitarios ni analytics invasivo en esta versión del sitio.

3. Finalidades

Usamos la información para responder consultas, analizar solicitudes, coordinar reuniones, operar el servicio, diagnosticar errores, mantener seguridad razonable y dar seguimiento a conversaciones comerciales iniciadas por la persona interesada.

4. Proveedores técnicos previstos

Para operar el sitio y sus canales se pueden usar proveedores técnicos como Amazon Web Services, AWS Lambda, Amazon DynamoDB, Amazon SES, Google Calendar y Google Meet. Estos servicios procesan datos solo en la medida necesaria para recibir solicitudes, almacenar leads, enviar notificaciones internas, coordinar reuniones o entregar la infraestructura técnica.

Al utilizar WhatsApp, la comunicación también queda sujeta a las condiciones y políticas del proveedor correspondiente.

5. Conservación

Los datos se conservarán durante el tiempo razonablemente necesario para gestionar la consulta, coordinar la reunión, mantener registros operativos o cumplir obligaciones aplicables. No se establece aquí un plazo legal específico inventado; los periodos definitivos deben revisarse según la operación real y la normativa aplicable.

6. Compartición

No vendemos datos personales. La información puede ser tratada por proveedores técnicos necesarios para operar el sitio y los canales de contacto, con acceso limitado a lo necesario para cumplir su función.

7. Seguridad

Aplicamos medidas razonables para proteger la información, como validación de formularios, controles de acceso a infraestructura, almacenamiento restringido, logs sanitizados y separación de secretos fuera del frontend. Ningún sistema conectado a internet puede garantizar seguridad absoluta.

8. Derechos

Cuando corresponda, las personas podrán solicitar acceso, corrección, actualización o eliminación de sus datos personales, de acuerdo con la normativa aplicable y el contexto de la relación existente.

9. Cambios

Esta Política de privacidad puede actualizarse cuando cambien las funcionalidades del sitio, los servicios ofrecidos o las obligaciones aplicables. La versión publicada indicará su fecha de última actualización.

10. Contacto

Cuando exista un canal oficial operativo para solicitudes de privacidad, se publicará en el sitio. No se publica aquí el correo operativo interno usado para notificaciones técnicas.

Este contenido es una base informativa inicial y puede requerir revisión profesional antes de una operación comercial de mayor escala.
